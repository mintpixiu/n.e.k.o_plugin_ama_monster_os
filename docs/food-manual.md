# 食用手册

**Ama Monster OS 0.7.0** · Food Manual · 离线快照（2026-11-22）

> 这是一份离线整理的外卖与优惠券参考，不是实时价格、库存、配送范围或活动。
> 券面额、满减门槛、起送价和配送时效都以各平台下单页为准。

## 一、这个房间是什么

- **今天吃什么**：从 49 道菜的池子里随机抽一道，附点单平台、先领哪张券、价格参考和取送说明；最近抽过的菜会被自动避开。
- **优惠券获取方式**：按平台整理美团、饿了么、京东外卖、淘宝闪购、抖音的领券入口、叠加提醒和**口令码 / 搜索词**示例。
- **平台入口**：每个平台都有官方入口链接，点开后在浏览器里继续操作。
- **外卖推荐**：全国连锁品牌和通用菜品，标注适用平台、优惠用法、价格参考和取送方式。
- **原版用法**：附上原版《隔离食用手册》菜谱网站的用法说明和入口。

整个房间只用插件内置的离线数据，不会联网、不会登录外卖账号、也不会代为下单。

## 二、优惠券怎么领（按平台）

### 美团

- 入口：https://www.meituan.com/
- **神券 / 膨胀券**：外卖 → 神券节或领券中心，午晚高峰前先领；膨胀券要在结算页手动勾选。
- **会员红包**：美团外卖会员每月红包包，在「我的 → 会员中心」领取，可与店铺满减叠加。
- **店铺券 + 店内活动**：进店先领店铺券，再看新客立减、收藏有礼、第二份半价。
- **拼好饭**：单人简餐频道，价格更低，但可选商家和配送范围有限。
- **口令码示例**：`12345`（常用领券口令）、`666666`（周三外卖节加码）、`88993`（新客/老号大额红包，资格以页面为准）。

### 饿了么

- 入口：https://www.ele.me/
- **超级吃货卡 / 吃货豆**：在「我的 → 超级吃货卡」领取，吃货豆可兑换红包。
- **天天领红包**：首页签到红包，连续签到金额会变大。
- **品牌馆 / 大牌券**：品牌馆和商超便利频道的大牌券、品牌日券。
- **店铺满减**：和平台红包叠加时，注意门槛是否按商品小计计算。
- **口令码示例**：`本地宝`（联名活动）、`13300`（红包口令，活动期）、`超星计划`（合作活动，名额有限）。

### 京东外卖

- 入口：https://www.jd.com/
- **PLUS 会员券包**：京东 App → 我的 → PLUS 会员中心领取。
- **京豆抵扣**：结算页可用京豆抵扣部分金额，注意比例上限。
- **品牌券 / 店铺券**：品牌馆和店铺页领券，注意可用商品范围。
- **满减 + 配送费券**：凑单满减的同时留意配送费减免。
- **搜索词示例**：`京东秒送`（外卖/秒送频道）、`外卖券`（领券活动入口）。

### 淘宝闪购

- 入口：https://www.taobao.com/
- **88VIP 权益**：淘宝 App → 我的 → 88VIP 会员中心领取专属券包。
- **店铺券 + 平台补贴**：先领店铺券，再看补贴和跨店满减能否叠加。
- **签到 / 任务红包**：闪购频道签到和做任务领红包。
- **限时秒杀**：适合水饮、零食和日用品，库存和配送范围以门店为准。
- **搜索词示例**：`闪购`（闪购/小时达频道）、`88VIP`（会员权益入口）。

### 抖音

- 入口：https://www.douyin.com/
- **团购套餐**：先买套餐券再到店核销，通常比单点便宜。
- **直播间专属券**：品牌直播间的券和秒杀套餐，注意可用门店和有效期。
- **达人探店券**：多为到店套餐，买前确认可用门店。
- **平台补贴券**：活动页和任务中心领取。
- **口令码示例**：`团购`、`抖音外卖`（搜索入口）；直播间的「主播口令」每次直播不同，无法写死，看到活动时按主播说明输入。

> 口令码来自公开活动整理（2026-11 快照），会随活动变化甚至失效，仅作领取方式示例；以各平台 App 内活动页为准，不要向任何页面提供账号密码或支付信息。

## 三、原版《隔离食用手册》怎么用

原版是云游君（YunYouJun）在 2022 年做的菜谱检索网站：勾选家里现有的食材和厨具，生成能做的菜并附视频教程。站点现在名为「食用手册」，原名「隔离食用手册」。

- 入口：https://cook.yunyoujun.cn/
- 作者说明：https://docs.yunyoujun.cn/projects/cook/

用法：

1. 打开网站，页面按「菜 / 肉 / 主食」列出手头可能有的食材。
2. 勾选现在有的食材，可以多选；不确定就先随便点几样。
3. 再选可用的厨具，例如电饭煲、炒锅、微波炉、空气炸锅。
4. 选择匹配模式：模糊 / 严格 / 生存。食材越少越适合生存模式；想多看几种做法用模糊模式。
5. 下方生成能做的菜谱列表，点开看步骤；部分菜谱可以直接跳到 B 站视频教程。
6. 换个食材组合就能重新生成一批菜谱，适合清冰箱或不知道吃什么的时候。

小提示：先勾食材再选厨具结果更准；生存模式适合只剩几样食材的时候；原版是第三方网站，菜谱以原站为准。

## 四、今天吃什么怎么用

- 点「抽一个」：从 49 道菜的离线池里随机抽一道菜。
- 再点「再抽一次」：插件会记住最近抽过的 8 道菜并避开，不会总反复出现同几个名字。
- 「券怎么领」：给出一个具体平台的领券顺序和口令示例。
- 「怎么到」：说明外卖配送 / 到店自取，并提示用地图 App 查最近门店。

## 五、外卖推荐怎么读

- **平台标签**：这个品牌通常可以在哪些外卖平台点到。
- **优惠**：会员日、团购券、店铺满减等常见用法。
- **取送**：外卖配送或到店自取；配送费、起送价和时效以下单页为准。
- **价格参考**：单人一餐的大致区间，不是实时价格。

## 六、数据边界

- 手册是 2026-11-22 的离线快照，不是实时数据，也不保证每个城市、每个门店都参加活动。
- 口令码和平台活动会变；平台入口链接指向官方首页，具体活动页以 App 内为准。
- 不含真实门店地址和路线；到店请用地图 App 搜索最近门店。
- 不抓取任何外卖平台数据，不登录外卖账号，不代为下单。
- 原版《隔离食用手册》是第三方网站，与本插件无隶属关系。

## 七、常见问题

- **为什么没有我家附近的门店？** 手册只做全国连锁和通用菜品参考，不含具体门店。
- **口令码输进去没反应？** 口令随活动变化，过期或换了活动就会失效，以 App 内活动页为准。
- **券在结算页用不了？** 检查门槛、有效期、适用商家和叠加规则，以结算页为准。
- **能自动领券或自动下单吗？** 不能。插件只展示离线攻略，不接触外卖账号。
- **抽签结果不想吃怎么办？** 再抽一次；最近抽过的菜会被避开。
