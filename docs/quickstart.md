# Ama Monster OS · 快速开始

**版本 0.1.0 Beta** · N.E.K.O Hosted UI 窗口预览

## 打开窗口

1. 打开 **N.E.K.O → 插件管理**。
2. 通过 **导入** 安装 `.neko-plugin`，或在 **开发模式** 里选择
   **加载未打包插件**，指向 `ama_monster_os` 文件夹。
3. 手动启动 **N.E.K.O Ama Monster OS**。自动启动默认关闭。
4. 进入插件详情，打开 **UI** 标签，选择 **Ama Monster OS** 面板。

## 窗口里能做什么

- **脉冲检查**：真正调用 Python 插件，等待一次回应，并刷新窗口状态。
- **刷新**：重新拉取 Hosted UI context。
- **最小化 / 展开 / 睡眠**：只改变窗口预览的显示状态，不会关闭 N.E.K.O。
- **日光 / 月光**：切换窗口配色。
- 首页、核心、系统桥、关于四个页面分别展示不同层的信息。

## 窗口里没有什么

0.1.0 Beta 是窗口预览：

- 对话、记忆、工具、外观模块标记为 **预留**，尚未实现。
- 没有原生窗口、进程控制、文件访问或语音管线。
- 不会把 N.E.K.O 的应用窗口嵌进这个面板。

## 语言

窗口跟随 N.E.K.O 的插件语言设置，提供 8 种语言：
`en`、`es`、`ja`、`ko`、`pt`、`ru`、`zh-CN`、`zh-TW`。

## 开发者入口

- `@ui.context(id="os_shell")` → 窗口状态
- `@ui.action(id="ama_pulse")` → 脉冲按钮
- `@plugin_entry(id="ama_system_contract")` → 读取系统桥契约
- `docs/system-contract.md` → 未来内置软件的接入说明

## 排障

| 现象 | 先看什么 |
|------|----------|
| 窗口一栏显示为空 | 插件是否已启动；Hosted UI context 是否加载 |
| 脉冲按钮报错 | 插件日志；确认 `ama_pulse` 已注册 |
| 活动隐私显示不可用 | 当前宿主没有提供 OS 活动信号；窗口会安全降级 |
| 看不到窗口 | 插件详情的 UI 分区；确认 `[plugin.ui]` 已启用 |
