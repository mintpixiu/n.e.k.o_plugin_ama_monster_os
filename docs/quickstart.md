# Ama Monster OS · 快速开始

**版本 0.1.0 Beta** · N.E.K.O Hosted UI 窗口预览

## 打开窗口

1. 打开 **N.E.K.O → 插件管理**。
2. 通过 **导入** 安装 `.neko-plugin`，或在 **开发模式** 里选择
   **加载未打包插件**，指向 `ama_monster_os` 文件夹。
3. 手动启动 **N.E.K.O Ama Monster OS**。自动启动默认关闭。
4. 进入插件详情，打开 **UI** 标签，选择 **Ama Monster OS** 面板。

## 窗口里能做什么

- **网络房间**：输入关键词联网搜索，查看结果并在浏览器中打开。
- **Steam 价格房**：按游戏名或 Steam AppID 查询当前最低价、历史最低价、低点日期和价差。
- **Steam 促销雷达**：显示当前促销、下一场 Steam 活动、下一场季节特卖和本地倒计时。
- **脉冲检查**：真正调用 Python 插件，等待一次回应，并刷新窗口状态。
- **刷新**：重新拉取 Hosted UI context。
- **最小化 / 展开 / 睡眠**：只改变窗口预览的显示状态，不会关闭 N.E.K.O。
- **日光 / 月光**：切换窗口配色。
- 首页、网络、Steam、核心、系统桥、关于六个页面分别展示不同层的信息。

## Steam 价格房怎么工作

- 搜索游戏名称或数字 Steam AppID。
- 数据来自 **CheapShark**，当前最低价和全站历史最低价均以 **USD** 显示。
- 历史最低是 CheapShark 的全站记录，不等同于 Steam 国区官方史低。
- 点击结果卡片上的查询会重新发起价格查询；搜索成功会刷新窗口状态。
- 需要网络；Steam 商店官方接口和 Steam 登录当前不可达。

## 促销雷达

- 数据来自 Valve 的 Steamworks 官方活动日程，本版本内置日历截至 **2026-11-07**。
- 当前下一场活动：**自动战斗 RPG 游戏节 2026**（11 月 16–23 日）。
- 当前下一场季节特卖：**Steam 冬季特卖 2026**（2026-12-17 至 2027-01-04）。
- 后续还包括 2027 春季、夏季、秋季特卖；秋季日期标注为待定。
- 日期按 Steam 官方太平洋时间（PT）显示；倒计时按本地时钟计算。
- 点击 **官方日程** 会在浏览器打开 Steamworks 文档。

### Steam 登录现在为什么没有做

Steam 密码不能交给第三方插件；Steam 登录页也不能放进 iframe。当前网络下
Steam Community / Steam API 均超时。因此 0.1.0 Beta 只显示 **登录暂缓**，
不提供假登录框；后续可接安全 OpenID 或用户自己的 Web API Key。

## 网络搜索怎么工作

搜索优先调用 N.E.K.O 内置的 **网络搜索（web_search）** 插件：

1. 如果它正在运行，就使用它原有的地区选择、缓存和重试策略。
2. 如果它没有运行，就回退到固定的 Bing RSS 端点。

只有查询文字会发送给搜索服务。窗口不会自动抓取网页、不会自动打开链接；
点击 **打开** 才会通过 N.E.K.O 的外部链接桥接进入你的浏览器。回退端点固定，
不接受任意 URL，结果链接也必须是 `http` / `https`。

> 如果内置网络搜索插件没有启动，窗口仍会使用 Bing RSS 回退；两种方式都不可用时
> 会明确显示“当前无法使用搜索”，不会假装有结果。

## 窗口里没有什么

0.1.0 Beta 是窗口预览：

- 不是内嵌浏览器，不能输入任意网址浏览。
- 对话、记忆、工具、外观模块标记为 **预留**，尚未实现。
- 没有原生窗口、进程控制、文件访问或语音管线。
- 不会把 N.E.K.O 的应用窗口嵌进这个面板。

## 语言

窗口跟随 N.E.K.O 的插件语言设置，提供 8 种语言：
`en`、`es`、`ja`、`ko`、`pt`、`ru`、`zh-CN`、`zh-TW`。

## 开发者入口

- `@ui.context(id="os_shell")` → 窗口状态
- `@ui.action(id="ama_pulse")` → 脉冲按钮
- `@ui.action(id="ama_web_search")` → 网络搜索
- `@ui.action(id="ama_steam_search")` → Steam 价格与历史最低
- `@plugin_entry(id="ama_system_contract")` → 读取系统桥契约
- `docs/system-contract.md` → 未来内置软件的接入说明

## 排障

| 现象 | 先看什么 |
|------|----------|
| 窗口一栏显示为空 | 插件是否已启动；Hosted UI context 是否加载 |
| 脉冲按钮报错 | 插件日志；确认 `ama_pulse` 已注册 |
| 搜索没有结果 | 换一个更短的关键词；查看内置 web_search 插件是否运行，或等待 Bing 回退 |
| 搜索显示不可用 | 检查网络连接；确认内置网络搜索插件或 Bing RSS 至少一个可用 |
| Steam 价格没有结果 | 换完整游戏名或数字 AppID；确认网络可访问 CheapShark |
| 促销倒计时和官方不一致 | 本版本日历是快照，Valve 可能已调整；以官方日程链接为准 |
| Steam 账号显示登录暂缓 | 0.1.0 Beta 未启用登录；不会收集密码，后续使用 OpenID/Web API Key |
| 活动隐私显示不可用 | 当前宿主没有提供 OS 活动信号；窗口会安全降级 |
| 看不到窗口 | 插件详情的 UI 分区；确认 `[plugin.ui]` 已启用 |

手动发布由仓库所有者完成；本插件不会自行上传或通知插件市场。
